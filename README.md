# academic-to-value-resume

把学术简历改写为企业愿意付钱的简历 —— 一个 Claude Code / Claude 的 Skill。

## 它解决什么问题

研究生、博士、博后投工业界岗位时，简历常常还是"学术汇报"：写"我研究了什么课题、发了什么论文、做了什么实验"。但企业 HR 只关心一件事——**你能帮我解决什么值钱的问题**。

这个 Skill 把视角从"我是什么学位/专业"切换到"我能帮公司解决什么问题"，用一套可复用的"付钱表达"方法重写每一段经历。

## 核心方法（三句话）

1. **付费点三分法**：公司只愿为三类事付钱——赚钱（多卖/新品）、省钱（降本/提效）、避险（合规/质量/安全）。每段经历必须归到至少一类。
2. **付钱表达三原则**：主语从"我"转向"问题"，从"技术过程"转向"商业结果"，数据挂到付费点。
3. **语言校准三层**：喊口号（"帮公司降本增效"）❌、藏价值（"解决了技术问题"）❌、自然动词 + 数据 + 具体落点（"可直接用于 XX 产品"）✅。

## 安装

把本仓库放到 Claude 的 skills 目录：

```
~/.claude/skills/academic-to-value-resume/
```

或作为项目级 skill 放到项目的 `.claude/skills/` 下。

## 使用

直接对 Claude 说：

- "帮我把这份学术简历改成企业愿意付钱的简历"
- "简历付钱化"
- "我是 XX 博士，帮我重新定位求职，写一份价值导向的简历"

触发词：学术简历改企业简历、简历付钱化、求职简历优化、改简历、resume for industry、value-based resume。

## 边界（重要）

本 Skill 的改写有明确红线：

- **不夸大**：参与 ≠ 解决/主导，个人只写个人做的事。
- **不改数据**：数据以用户为准，不擅自"修正"。
- **不虚构**：改写是换"表达框架"，不是换"事实"。
